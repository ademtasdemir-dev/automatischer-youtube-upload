2. Was das Programm tut

„Automatischer YouTube-Upload“ ist ein privates Programm, das ausschließlich auf dem PC des Verantwortlichen läuft. Es lädt Videos des Verantwortlichen über die YouTube Data API (YouTube API Services) auf dessen eigenen YouTube-Kanal hoch und setzt Titel, Beschreibung, Tags, Sichtbarkeit und Vorschaubild.

3. Welche Daten verarbeitet werden

  • Google-Anmeldung: Bei der Anmeldung erteilt der Kontoinhaber dem Programm über Google OAuth die Berechtigung youtube.upload. Das dabei ausgestellte Zugriffstoken wird nur lokal auf dem PC in der Datei token.json gespeichert.
  • Videos und Angaben zum Video: Videodatei, Vorschaubild, Titel, Beschreibung und Tags werden direkt vom PC an YouTube übertragen.
  • Das Programm liest keine weiteren Daten aus dem Google-Konto, keine Kontakte, keine Kommentare und keine Daten anderer Personen.

4. Weitergabe und Speicherung

Es gibt keinen eigenen Server. Daten werden nur an Google/YouTube übertragen, damit der Upload stattfinden kann. Es findet keine Weitergabe an sonstige Dritte, keine Werbung, kein Tracking und keine Analyse statt. Nach einem erfolgreichen Upload löscht das Programm die hochgeladenen Dateien vom PC.

5. YouTube und Google

Das Programm nutzt die YouTube API Services. Mit der Nutzung gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Die Berechtigung kann jederzeit in den Google-Kontoeinstellungen unter „Drittanbieter-Apps und -Dienste“ widerrufen werden. Das lokale Token wird gelöscht, indem die Datei token.json entfernt wird.

6. Diese Webseite

Diese Seite wird über GitHub Pages bereitgestellt. GitHub kann beim Aufruf technische Daten wie die IP-Adresse verarbeiten. Näheres in der Datenschutzerklärung von GitHub. Diese Seite selbst setzt keine Cookies und nutzt keine Analyse-Werkzeuge.
